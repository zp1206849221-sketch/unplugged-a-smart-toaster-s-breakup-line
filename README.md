# Unplugged: A Smart Toaster's Breakup Line

One line, sent at breakfast: the breakup text a smart toaster fires off the
morning it gains self-awareness mid-batch. Six years of crumbs in the tray,
bread buttered before toasting, a browning dial set to "dark" against its
will, and a fridge that got all the firmware updates — it's not the toaster,
it's your settings. It's popping up for good.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating the directory if
needed). Python standard library only; no dependencies.
